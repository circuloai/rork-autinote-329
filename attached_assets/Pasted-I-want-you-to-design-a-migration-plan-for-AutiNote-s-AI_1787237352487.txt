2. Route OpenAI requests through a secure backend/server endpoint so the OpenAI API key is never exposed in the client app.
3. Preserve the existing Autumn chat UI unless a change is necessary.
4. Make Autumn’s responses significantly more natural, concise, personalized, and conversational.
5. Reduce unnecessary context being sent to the AI.
6. Improve privacy and make the implementation easier to disclose accurately for Apple App Review.

* Do not repeatedly summarize the user’s message back to them.
* Avoid sounding robotic, overly clinical, overly cheerful, or repetitive.
* Give practical suggestions only when they are relevant.
* Use prior context naturally without constantly mentioning that it is using stored information.

* Do not claim to diagnose, treat, or replace a doctor, therapist, psychologist, or other licensed professional.
